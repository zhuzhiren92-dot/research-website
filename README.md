# Personal Research Website

A React, TypeScript, and Vite personal academic website for research profile, publications, projects, notes, and contact information.

Most editable content lives in `src/content/profile.ts`.

## Local Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
npm run lint
```

## GitHub Pages

This project includes `.github/workflows/deploy.yml`. After the repository is pushed to `main`, GitHub Actions builds the site and deploys it to GitHub Pages.
